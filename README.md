# IoT Hydroponic Monitoring System

ESP32-based hydroponic monitoring and automation system.

## Features
- pH Monitoring
- TDS Monitoring
- Water Temperature Monitoring
- Water Level Monitoring
- Turbidity Monitoring
- Light Intensity Monitoring
- OLED Display
- Automatic Nutrient Control
- Automatic pH Up/Down Control

## Hardware
- ESP32
- DS18B20
- HC-SR04
- TDS Sensor
- pH Sensor
- Turbidity Sensor
- OLED SSD1306

## Software
- Arduino IDE
- Wokwi Simulator
